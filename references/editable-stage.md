# 直接制作可编辑 PPT

仅在用户确认逐页文案后进入本阶段。读取当前可用的 `Presentations` 技能，使用其支持的演示文稿对象与导出流程；不要预设某个旧版本 SDK 或硬编码不存在的方法。按环境需要用 `load_workspace_dependencies` 定位运行时。没有对应工具时先发现能力，再选择等效对象式方案并如实记录。

## 已确认文案与参考页指导布局，论文提供事实

以已确认的 `content-plan.json` 为内容依据，以实际参考页、页面模式和 `style-lock.json` 决定位置、比例、色彩和视觉层级；直接创建可编辑对象，不生成整页设计图片再拆解。文字、公式、数字与科学关系回查原文。排版可精简表达，但不能擅自改变已确认的核心主张或内容范围；发现需实质修正文案的事实问题时，说明依据并让用户确认修订内容。

逐页建立 `element-map.json`：页 ID；每个元素的类型、画布坐标与单位、逻辑边界框(x,y,w,h)、层级、内容来源、字体/颜色；在 PPT 中的对象 ID 或名称；是否保留位图及原因。文字记录字号单位、字重、局部强调、分点/缩进/段距；表格记录组边界、行高与数值对齐。连接线记录源节点和目标节点 ID、锚点/连接侧、流向及分支标签，便于核对端点。字号使用目标物理画布的字号系统，不把参考图像素当作 pt。

## 原生对象与科研证据

|元素|制作方式|检查点|
|---|---|---|
|标题、要点、图注、列头|原生文本框|可选择修改，换行与顺序合理|
|分区、细框、语义色块|原生形状|填色、边线、层级正确|
|方法模块与流程|原生节点与连接线|箭头接对端点，分支/汇合正确；节点命名 diagram-* 便于静态审计|
|表格|原生表格|行列、单位、加粗、跨列含义与原文一致|
|曲线/柱状图|有可核对数据时用原生图表及嵌入数据|轴、图例、尺度、数值、误差线和数据编辑可用|
|公式|工具支持时用原生数学公式；否则用可编辑 LaTeX/源文本并交付源|普通文本或矢量图不能冒充原生公式；保留降级说明|
|照片、论文生成样例、热图、分割图|目标论文的原始科研图片|像素证据与原图一致；说明图像本身不可编辑|
|复杂论文插图|优先拆模块；无法可靠还原时保留原图并添加可编辑说明|明确哪些部分仍是位图，不能夸称全部元素可编辑|

不把整页图片铺底再叠几行文字。复杂科研图保留位图是合理的，布局、标签和可制作部分仍应原生化。不要为了提高可编辑率破坏原图信息，或把一条曲线拆成猜测的数据点。

## 制作顺序与验证

1. 根据锁定视觉系统设置 16:9 画布、字体、色彩及基础标题规则。
2. 先制作一张方法页和一张证据页，渲染并与实际参考页、已确认文案比较，检查对象编辑与数据编辑，再推广到全套。
3. 先放科学证据与关键关系，再加文字与注释。流程节点、连接线和对应标签一起检查。尽量使用绑定节点的连接器；移动或缩放节点后重算/更新端点，避免手动画线留在旧位置。
4. 不凭 SDK 的 `head` / `tail` 等字段名推断实际箭头方向；先渲染代表性连线，核对箭头是否指向目标节点，再应用到全套。检查源/目标锚点贴合对应节点边界，箭头不悬空、不指向无关对象，也不穿过文字。
5. 逐页执行[质量门槛](quality-gates.md)的“渲染—检查—修复—复检”闭环，修复遮挡、溢出、错误换行、字体替换、图片裁切、公式错位、组件错位及连接异常。短中文不可用英语窄字体强行压缩。
6. 在可用编辑器或对象 API 中实际修改代表性的文本、表格单元格和方法节点；有原生图表时检查其数据可编辑。用副本验证或恢复测试改动后重新导出，避免改坏交付文件。记录验证范围，不宣称未经测试的软件兼容性。
7. 比较完整页序与已确认内容计划，确认主讲/备份、总页数、结论与证据没有丢失。

## 保持视觉层级

- **字体与强调**：区分标题、分组引导、正文、注释；局部加粗用文本 run 表达，不把整段统一成常规灰字。替代字体须有对应语言覆盖和真实可用的字重，并核对混排字高、基线与换行。不能仅凭字体名称写入成功判断匹配。
- **项目符号**：设置真实项目符号、悬挂缩进与段距；续行对齐文字起点。不在导出时退化为散行文本，也不靠空格模拟缩进。
- **表格**：保留设置组间的细线或留白、重点行字重和小数位对齐。导出不支持某种边线时，改用等效原生分隔或组间距。修复文字溢出后重新核对行高与列宽。
- **公式**：逐一核对大小写、上下标、字形和正斜体；如 C_V 与 C_v 不同，不能当作排版近似接受。公式文本可编辑不等于数学结构正确，降级时照实说明。
- **图示与注释**：保持主图占比、细边线、圆角尺度、连接端口和条件标签位置。图注贴近证据，来源/页码保持固定位置；标签不得意外遮挡科研证据。

交付 PPTX、最终渲染预览与制作源文件；对保留位图的科学素材及公式等降级部分作简短说明。包含必要原始图片与数据，源文件引用相对路径，不依赖作者机器的绝对路径或缓存。不要打包凭据、个人环境配置或无关工作区文件。
